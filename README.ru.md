# Blueprint Wand

🇬🇧 [English version](README.md)

Мод для **Minecraft 1.21.1 (NeoForge)**. Жезл чертежей выделяет область в мире и сохраняет постройку
в текстовый JSON-файл, который удобно читать человеку и ИИ (например, Claude).
Сохранённые схематики можно просмотреть рамкой, повернуть и вставить обратно.

## Возможности

- Предмет «Жезл чертежей» (внешне — зачарованная палка). Крафт: палка + бумага.
- Выделение двумя точками, область подсвечивается рамкой, пока жезл в руке.
- `/schem save <имя>` сохраняет область в `schematics/<имя>.json` в папке игры.
- `/schem preview <имя> ...` показывает схематику полупрозрачными блоками внутри жёлтой рамки там, где она встанет, `/schem confirm` вставляет её. Постройки больше 40 000 непустых блоков показываются только рамкой; блоки дальше 64 блоков от тебя не рисуются.
- Имена сохранённых схематик из папки `schematics` подсказываются автоматически при вводе `/schem paste` и `/schem preview`.
- `/schem paste <имя> ...` вставляет сразу, с поворотом на 90 / 180 / 270° по желанию.
- `/schem undo` откатывает последнюю вставку.
- Предмет **«Список схематик»** (крафт: книга + бумага): ПКМ открывает экран со всеми схематиками из папки (с размерами). Выбери проект, поворот, место (куда смотришь / под собой) и очистку воздуха, нажми **«Предпросмотр»** (жёлтая рамка), затем снова открой список и нажми **«Вставить»**. Кнопки выполняют те же команды `/schem`, поэтому нужны права оператора.
- Сохраняются блоки со всеми свойствами (`facing`, `half`, `waterlogged` и т. д.) и список блоков с данными (сундуки, таблички).
  Содержимое сундуков, NBT и сущности не сохраняются.
- Переводы на английский и русский (`assets/blueprintwand/lang`).

## Управление

| Действие | Результат |
|---|---|
| ЛКМ по блоку жезлом | Точка 1 (синяя рамка) |
| ПКМ по блоку жезлом | Точка 2 (красная рамка) |
| Shift + ЛКМ | Сбросить выделение |

Зелёная рамка — вся территория, которая будет сохранена. Максимальный размер — 1 000 000 блоков.

## Команды

| Команда | Описание |
|---|---|
| `/schem save <имя>` | Сохранить выделенную область |
| `/schem list` | Список схематик |
| `/schem preview <имя> [r90\|r180\|r270] [x y z] [with_air]` | Жёлтая рамка предпросмотра (повторный запуск сдвигает или поворачивает) |
| `/schem confirm` / `/schem cancel` | Вставить показанную схематику / убрать предпросмотр |
| `/schem paste <имя> [r90\|r180\|r270] [x y z] [with_air]` | Вставить сразу |
| `/schem undo` | Откатить последнюю вставку |

- Минимальный угол схематики (наименьшие x, y, z) ставится в указанную точку, по умолчанию — в блок, где ты стоишь.
  Координаты могут быть относительными (`~ ~ ~`) или взятыми из `origin_world` файла.
- Поворот идёт по часовой стрелке, состояния блоков (лестницы, двери и т. д.) поворачиваются вместе с постройкой.
- `with_air` вставляет и воздух из схематики, то есть очищает область. Без него воздух пропускается.
- Вставка, предпросмотр и откат требуют прав оператора (уровень 2; в одиночной игре — включённые читы).
- Блоки ставятся без обновления соседей, поэтому ничего не отваливается и не падает.
  Блоки из отсутствующих модов пропускаются, их список выводится в чат.
- Откат не восстанавливает содержимое сундуков и другие данные блоков.

## Формат файла

```json
{
  "format": "blueprintwand-1",
  "size": {"x": 5, "y": 4, "z": 5},
  "origin_world": {"x": 100, "y": 64, "z": -20},
  "palette": {".": "minecraft:air", "A": "minecraft:stone_bricks"},
  "layers": [
    {"y": 0, "rows": ["AAAAA", "A...A", "A...A", "A...A", "AAAAA"]}
  ]
}
```

`layers[i]` — горизонтальный срез на высоте `i` (0 — низ), `rows[j]` — строка `z = j` (0 — север),
номер символа в строке — `x` (0 — запад). Символ — ключ из `palette`, `.` — воздух.

Совет: отправь `.json` ИИ-ассистенту, чтобы он доработал постройку, и вставь правленый файл обратно.
Размеры `size`, число слоёв и длина каждой строки должны совпадать.

## Сборка

Нужны JDK 21 и Gradle 8.10+.

```bash
gradle wrapper        # один раз, создаст gradlew
./gradlew build       # jar окажется в build/libs/
./gradlew runClient   # запустить игру для теста
```

Версия NeoForge задаётся в `build.gradle` (`neoForge { version = ... }`).

## Установка

Положи jar из `build/libs/` в папку `mods` клиента (и сервера, если играешь на сервере).
Мод нужен с обеих сторон (NeoForge 1.21.1).

## История версий

- **1.4.0** — полупрозрачный предпросмотр блоков: `/schem preview` (и список) показывает настоящие блоки схематики как «призрак» с учётом поворота.
- **1.3.0** — предмет «Список схематик»: экран со всеми сохранёнными проектами, выбор поворота и места, предпросмотр и вставка.
- **1.2.1** — имена сохранённых схематик подсказываются (Tab) в `/schem paste` и `/schem preview`.
- **1.2.0** — поворот, предпросмотр рамкой (`/schem preview`, `/schem confirm`, `/schem cancel`), английский перевод.
- **1.1.0** — `/schem paste` и `/schem undo`.
- **1.0.0** — жезл, выделение, `/schem save`, `/schem list`.
